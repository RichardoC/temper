### Three readings that matter for P3

1. **T=0.4 buys literally nothing: zero passing canvases across all 9
   problems.** Every flip is at T≥0.8. The reachable region starts *above* the
   M2 cells' T=0.2 anchor and above the design's implicit "mild diversity"
   assumption — so the design's child-temperature ladder (clone temp +0.2 from a
   T=0.2 base = 0.4) starts **below** the only band that has been measured to
   reach anything. C-full's clone ladder should be re-based on T≥0.8, which is a
   parameter decision the parent should make before P3 (it is a §4.3 protocol
   deviation and needs to be declared as one).
2. **HumanEval_17_parse_music is REACHABLE (3 OK at T=0.8).** It was a
   deterministic 4/4 EXCLUSION in both the s256 and s512 cells and is one of the
   design's two "prompt-shape pathology" problems. The problem was always
   solvable; Dream's T=0.2 mode simply never produced it. This is the single
   most favourable fact for steering in the whole probe — and it is also a
   warning: the exclusion cohort is a *diversity* problem, not a prompt-shape
   problem, which the design classified it as.
3. **The quartet is PARTIALLY reachable: 0 and 21 never, 4 and 20 at T=1.2
   only.** Combined with the C-hint 0/4, the picture is a genuine mode-lock at
   low temperature with modes that exist but only at high temperature. Design
   review B predicted "GO driven by 17/19 with ≤1–2 of the type quartet" —
   measured: **GO driven by 11/24/17 with exactly 2 of the quartet.** Review B's
   direction was right; its specific problems were wrong (19 was never reachable;
   11 was).

### Two cohort-integrity findings (both fixed before the probe ran)

- **Wrong-problem hazard.** The design names cohorts by *HumanEval number*, but
  the vendored file omits HumanEval_22, so position ≠ number past 21: positional
  index 24 is `HumanEval_25_factorize` while number 24 is
  `HumanEval_24_largest_divisor`. Selecting the P1 set positionally would have
  silently run the wrong problem. Fixed by `--problem-numbers` (mutually
  exclusive with `--problem-indices`, refusal on absent numbers), commit
  `5defab8`.
- **Seed confound (operator ruling, paired-on-seed).** Flat seeds would have
  given T0.4 seeds 0–3, T0.8 seeds 4–7, T1.2 seeds 8–11, confounding temperature
  with seed exactly where the gate is read. Canvases are now laid out
  `[temp0 × K, temp1 × K, …]` with canvas *j* seeded `base_seed + (j mod K)`, so
  the K canvases at every temperature share one seed set; recorded as
  `seed_paired_across_temps: true` in the run meta. Commit `489144e`.
- **Spec-deviation incident (recorded).** The first P1 launch passed a 3-entry
  temperature list, which the driver read as *one canvas per temperature* (27
  canvases) instead of K=4 per temperature (108). Aborted ~2 min in before any
  row was written; artifacts quarantined to `/tmp/m3_abandoned/`; nothing
  entered the repo.

## P2 — engine equivalence: **PASS 4/4**, after fixing two real engine bugs

Gate: HumanEval_0, K=4, steps=128, canvas=384, T=0.2, seed=0 — steer loop in
all-off mode vs `dream.sample`:

```
p0..p3: IDENTICAL, sha f03ee274af533992
P2 EQUIVALENCE: PASS (4/4 bit-identical)
```

That sha is also the **committed** s128 sidecar for all four particles, so the
gate is confirmed against banked artifacts, not merely against a fresh reference.

The gate earned its keep on the first attempt (0/4):

1. **Missing `torch.no_grad()`.** `diffusion_generate` — the only path the
   unsteered cells take — is decorated `@torch.no_grad()` (vendored
   `generation_utils.py:296`). The loop called the model with grad enabled,
   which on MPS selects different kernels and therefore a different float path.
   Fixed; pinned by a test asserting every forward sees grad disabled.
2. **All-off split at checkpoints.** A first version of the D4 capture hook made
   all-off mode walk the checkpoint grid, which re-entered the stepping function
   per checkpoint and re-seeded the RNG mid-canvas. All-off now runs one
   unbroken segment per particle and fires the observation hook from inside it;
   pinned by a test that adding the hook does not change the canvas.

A third, uninteresting cause was in the *script* (the reference call omitted
`temperatures`, so `dream.sample` fell into `_normalize_particles`' design cycle
T=0.2/0.4/0.6/0.8 instead of flat T=0.2). Both sides now pass explicit
temperatures and algs, mirroring the bench driver.

D2 replay: `temper steer-replay` re-derives every decision from the log alone
(no GPU) on a real steered game log, and the poisoning tests
(verdict / decision / dropped-event) all raise `ReplayMismatch`.

**The design's §3.2 simulation replicates on real canvases.** The sim predicted
informed-class recall of 0–1/36 at ≤85 % committed; measured **0/5 at ≤75 %**.
The design hoped the real loop's confidence-ranked, structure-first commit order
would push recall *above* the sim's uniform-random curve — it did not. All
mid-canopy discriminative power sits at the final checkpoint, where the
any-error screen is exact. **D4's decision (design §7 D4 demotion rule): act on
it.** The verdict config is repinned **v0 → v1**:

- `patience.consecutive_checkpoints` **2 → 3** (with measured per-checkpoint
  recall 0 until the final step, the tighter patience costs no true-kill latency
  and further guards the false-kill side, which measured 0/12 at proximity 1);
- `hole_proximity_lines` stays **1** (0 false kills measured there);
- informed classes, R0 fatal flags, R2 markers, checkpoint grid and emission
  rule all **unchanged**;
- the demotion text is committed in the config: **C-kill is dropped first** if
  budget is cut, **C-full's mid-decode rung density reduces first**, and any
  C-full result's honest summary **demotes to "ladder + final screen"** unless
  C-full − C-screen ≥ +2.

## Recommendation on P3

**Recommendation: launch P3, with two parameter decisions first.**

The GO is real and is the strongest result in the probe: 5/9 reachable with the
stratified rule satisfied on all three arms, 0/12 false kills, R1 verified exact
at the final checkpoint, and an engine proven bit-identical to the unsteered
baseline at 0.11 % verifier overhead. The mechanism question is now askable
rather than assumed.

Two things must be decided *before* C-null/C-full launch, because both are §4.3
protocol deviations that would otherwise be discovered mid-cell:

1. **Re-base the clone temperature ladder on the measured reachable band.**
   P1 says the reachable region starts at T≥0.8; T=0.4 produced zero passing
   canvases out of 36. The design's "children temp +0.2, capped 0.8" applied to a
   T=0.2 base gives children at 0.4 — below the entire measured reachable band.
   C-full's ladder should start at 0.8 (e.g. base 0.8, children 0.8/1.0/1.2 capped
   at 1.2). This is a real design change and needs the parent's explicit approval
   and a declared deviation line in every C-full record.
2. **Expect the pre-registered primary comparison to be decided by the final
   screen, not by mid-decode killing.** D4 measured zero mid-canvas yield, so
   C-full − C-screen is the number that will carry the mechanism claim, and it
   is priced conservatively. That matches design review B's prediction
   (C-full − C-screen ∈ {0, +1}) rather than the design's hope.

Also worth flagging for the C-null analysis: **HumanEval_17's reachability at
T=0.8** means the exclusion cohort joins the ladder-reachable set. Any C-full
flip on 17 will be reproduced by C-null/C-screen and must not be counted as
mechanism evidence — the §4.2 attribution gate's outside-cohort requirement is
now stricter than the design text assumed.
